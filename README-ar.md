# دفتر الحفظ - مشروع تطبيق أندرويد

هذا المجلد هو التطبيق كاملاً. لتحويله إلى ملف APK تثبّته على جوالك، اتبع هذه الخطوات مرة واحدة (مجانية، وتحتاج حاسوباً ومتصفحاً):

1. أنشئ حساباً مجانياً في github.com، ثم اضغط New repository، واكتب أي اسم (مثلاً hifz)، واختر Private، ثم Create repository.
2. في صفحة المستودع اضغط "uploading an existing file". فك ضغط هذا الملف، وافتح المجلد، وحدّد كل ما بداخله (app و build.gradle و settings.gradle و gradle.properties) واسحبه إلى الصفحة. انتظر انتهاء الرفع ثم اضغط Commit changes.
3. أضف ملف البناء: اضغط Add file ثم Create new file. في خانة الاسم اكتب بالضبط:  .github/workflows/build.yml  (عند كتابة الشرطة المائلة تتحول المجلدات تلقائياً). افتح الملف build-workflow.yml من هذا المجلد، وانسخ كل محتواه والصقه في المحرر، ثم Commit changes.
4. اذهب إلى تبويب Actions. سيبدأ البناء تلقائياً (يأخذ نحو 4 دقائق). عندما تظهر علامة صح خضراء، افتح العملية وانزل إلى Artifacts، ثم نزّل hifz-notebook-apk.
5. فك ضغط الملف المنزَّل، وانقل app-debug.apk إلى جوالك وافتحه. إن طلب الجوال السماح بتثبيت تطبيقات من خارج المتجر فوافق.

إذا ظهرت علامة X حمراء في Actions، افتح العملية وانسخ سطر الخطأ وأرسله لي لأصلحه.
